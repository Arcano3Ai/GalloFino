## 💈 Sobre el Proyecto

Sitio web oficial de **Gallo Fino Barber**, desarrollado con **Next.js**, **TypeScript**, **Tailwind CSS** y metadatos **OpenGraph** optimizados para redes sociales y previsualización de enlaces en WhatsApp.

### ✨ Características
- 🇲🇽 🇺🇸 **Bilingüe (Español / Inglés)**
- 🌓 **Modo Oscuro / Claro** con estética norteña-urbana
- 🎵 **Audio Player Integrado** con canción oficial
- ✂ **Catálogo de Servicios y Reserva por WhatsApp**
- 🧢 **Tienda Oficial (Merch)**
- 📍 **Ubicación en Fremont, OH & Monterrey, NL**

---

## 🚀 Inicio Rápido

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000` en el navegador.
